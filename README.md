# MedScribe AI

AI-assisted SOAP note drafting for clinicians. Converts consultation
recordings into structured draft notes for review and approval.

## Status

Early development. Nothing is deployed yet.

## Important

All AI-generated notes are drafts only. No note is a final medical
record until a licensed clinician reviews and approves it. This system
does not diagnose patients or make clinical decisions.

## Structure

- `backend/` — NestJS API and background processing
- `frontend/` — Nuxt 4 clinician-facing application

Setup instructions will be added as each service comes online.
